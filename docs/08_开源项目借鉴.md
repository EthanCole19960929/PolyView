## 1. 现状速查（读 `feat/picking-program` 得到）

- `SceneRenderer.Render()`：清屏 → **先画网格**（`LineList`，`DepthStencilDescription.Default`，写深度）→ 再逐个画模型。
- 选中高亮：像素着色器里 `color = lerp(color, 橙色, Highlight * 0.45)`，整个模型被染橙——这就是用户指出的问题。
- 网格：`BuildGrid(min,max)` 按场景包围盒生成有限条线，没有淡出。
- 拾取：`Core/Picking.cs` 有 `CreateRay` / `RayAabb` / `RayTriangle`，`Pick()` 对所有物体所有三角形线性遍历。
- 大纲：`OutlinerPanel` 是平铺 `ObservableCollection<OutlinerItem>`，有 `depth` 参数和眼睛开关，相机/灯光是写死的两行。
- 还没有：手柄、撤销/重做、灯光图标。

## 2. 【P0】选中描边（只描橙色外轮廓）

**来源**
- Helix：[`psEffectOutlineQuadStencil.hlsl`](https://github.com/helix-toolkit/helix-toolkit/blob/develop3/Source/HelixToolkit.Native.ShaderBuilder/PS/psEffectOutlineQuadStencil.hlsl)、[`psEffectMeshBorderHighlight.hlsl`](https://github.com/helix-toolkit/helix-toolkit/blob/develop3/Source/HelixToolkit.Native.ShaderBuilder/PS/psEffectMeshBorderHighlight.hlsl)、[`PostEffectMeshBorderHighlight.cs`](https://github.com/helix-toolkit/helix-toolkit/blob/develop3/Source/HelixToolkit.SharpDX.SharedModel/Model/Elements3D/PostEffects/PostEffectMeshBorderHighlight.cs)
- Flax（只看思路）：`Source/Editor/Gizmo/SelectionOutline.cs`

**怎么做的**
- Helix：① 把选中物体用纯色画进一张离屏遮罩图（stencil pass 只输出 `Color`）；② 全屏四边形对遮罩做 4 个对角采样取 `max`（膨胀），③ 再减去原遮罩就只剩一圈边，叠加到主画面。摘录（MIT）：
```hlsl
float4 c = texDiffuseMap.Sample(samplerSurface, input.Tex + float2(offX, offY));
c = max(c, texDiffuseMap.Sample(samplerSurface, input.Tex - float2(offX, offY)));
c = max(c, texDiffuseMap.Sample(samplerSurface, input.Tex + float2(-offX, offY)));
c = max(c, texDiffuseMap.Sample(samplerSurface, input.Tex - float2(-offX, offY)));
color = max(color, c);
```
- Flax 思路：申请一张临时 `D32_Float` 深度图，只把选中物体画进去（“自定义深度”），后处理材质比较自定义深度和场景深度，在自定义深度的边缘处输出描边色，被遮挡的部分颜色变淡。好处是被别的物体挡住的轮廓也能看见（Blender 也是这样）。

**PolyView 怎么接**（负责人：program，文件 `SceneRenderer.cs` + 新增 `Shaders/Outline.hlsl`）
1. 删掉像素着色器里的 `lerp(..., Highlight*0.45)`，模型保持原色。
2. `Resize()` 里多建一张 `R8_UNorm` 遮罩纹理（RTV + SRV）。
3. `Render()` 画完模型后：把 `SelectedId` 物体用一个只输出 1 的像素着色器画进遮罩（深度测试关，这样被挡住的部分也有轮廓）。
4. 全屏三角形 pass，Blend 开 alpha，读遮罩做边缘检测，输出 Blender 橙 `#FFA000`（活动物体），描边宽 2 px：
```hlsl
// PolyView Outline.hlsl（novel 重写，思路同 Helix）
Texture2D<float> Mask : register(t0);
cbuffer C : register(b0) { float2 TexelSize; float Width; float pad; float4 OutlineColor; };
float4 PSOutline(float4 pos : SV_Position) : SV_Target {
    int2 p = int2(pos.xy);
    float center = Mask.Load(int3(p, 0));
    float m = 0;
    [unroll] for (int y = -2; y <= 2; y++)
    [unroll] for (int x = -2; x <= 2; x++)
        m = max(m, Mask.Load(int3(p + int2(x, y), 0)));
    float edge = m * (1 - center);          // 外面一圈 = 膨胀 - 原图
    return float4(OutlineColor.rgb, OutlineColor.a * edge);
}
```
5. 进阶（P1）：物体很大或想要 Blender 那种粗而均匀的线时，换成 Jump Flood（JFA）距离场：log2(宽度) 次 pass 就能得到任意宽度的平滑外轮廓。

验收：长方体选中后只有外轮廓一圈橙线，面保持灰色（对应 test all 在 `审查.md` 里记的不通过项）。

## 3. 【P0】地面网格的深度遮挡与淡出

**来源**：Helix [`vsPlaneGrid.hlsl`](https://github.com/helix-toolkit/helix-toolkit/blob/develop3/Source/HelixToolkit.Native.ShaderBuilder/VS/vsPlaneGrid.hlsl) / [`psPlaneGrid.hlsl`](https://github.com/helix-toolkit/helix-toolkit/blob/develop3/Source/HelixToolkit.Native.ShaderBuilder/PS/psPlaneGrid.hlsl)；Stride `GridGizmoBase.cs` / `ViewportGridGizmo.cs`；Flax 思路 `Source/Editor/Gizmo/GridGizmo.cs`。

**怎么做的**：Helix 不用线段，而是画一个大平面，在像素着色器里用 `frac(uv / spacing)` 判断是否在线上，并按到相机距离淡出 alpha（摘录，MIT）：
```hlsl
grid = whengt(whenle(frac(input.uv.x / gridSpacing), gridThickness) + whenle(frac(input.uv.y / gridSpacing), gridThickness), 0);
float dist = length(input.wp - vEyePos.xyz);
color.a = lerp(color.a, 0, clamp(abs(vFrustum.w * fadingFactor) / max(vFrustum.w - dist, 0), 0, 1));
```
平面本身就是真实几何，走正常深度测试，自然被模型挡住。

**PolyView 现状的问题**：网格先画且写深度，理论上会被长方体挡住；用户截图里网格透过长方体，说明（按可能性排序）要检查：① 深度视图是否真的绑上（`_depthView` 在 `Resize` 后重建，渲染时用的是不是新的）；② 投影近平面太小（`GetViewProjection` 里 near 是否按 `meshRadius` 取了极小值，导致精度不够）；③ 模型 pass 是否切了一个关深度的状态。program 先用 RenderDoc / PIX 抓一帧确认。

**PolyView 怎么接**（program，`SceneRenderer.cs` + 新增 `Shaders/Grid.hlsl`）
1. 网格改到**模型之后**画：深度测试 `LessEqual`、**不写深度**、alpha 混合。这样永远被模型正确遮挡，也不会挡住后画的半透明东西。
2. 用全屏“无限网格”：顶点着色器出全屏三角形，像素着色器反投影出射线与 y=0 平面求交，用 `fwidth` 做抗锯齿线，并自己写 `SV_Depth`：
```hlsl
// PolyView Grid.hlsl（novel 重写）。行向量约定：clip = float4(p,1) * ViewProj
cbuffer G : register(b0) { float4x4 ViewProj; float4x4 InvViewProj; float3 Eye; float FadeDist; };
struct O { float4 c : SV_Target; float d : SV_Depth; };
O PSGrid(float4 pos : SV_Position, float2 ndc : TEXCOORD0) {
    float4 a = mul(float4(ndc, 0, 1), InvViewProj); a /= a.w;   // 近平面点
    float4 b = mul(float4(ndc, 1, 1), InvViewProj); b /= b.w;   // 远平面点
    float t = -a.y / (b.y - a.y); if (t <= 0) discard;
    float3 p = a.xyz + t * (b.xyz - a.xyz);
    float2 g = abs(frac(p.xz - 0.5) - 0.5) / fwidth(p.xz);      // 1 m 一格
    float line = 1 - saturate(min(g.x, g.y));
    float3 col = abs(p.z) < fwidth(p.z) ? float3(0.85,0.2,0.25)  // X 轴红
              : abs(p.x) < fwidth(p.x) ? float3(0.45,0.75,0.2)   // Blender Y 轴（PolyView -Z）绿
              : float3(0.33,0.33,0.33);
    float fade = 1 - saturate(length(p - Eye) / FadeDist);
    float4 c = mul(float4(p, 1), ViewProj);
    O o; o.c = float4(col, line * fade); o.d = c.z / c.w; return o;
}
```
3. Blender 的 10 倍细分：再叠一层 `p.xz / 10` 的粗线，按相机高度插值透明度。
4. `BuildGrid` / `_gridVertices` 可以保留做兼容开关，默认走新网格。

## 4. 【P0】移动/旋转/缩放手柄的外观与交互

### 4.1 恒定屏幕尺寸
- Stride [`TransformationGizmo.cs`](https://github.com/stride3d/stride/blob/master/sources/editor/Stride.Assets.Presentation.Wpf/AssetEditors/Gizmos/TransformationGizmo.cs) 第 56、230 行（摘录，MIT）：
```csharp
public float DefaultScale => GizmoDefaultSize / GraphicsDevice.Presenter.BackBuffer.Height;
...
return SizeFactor * DefaultScale * 2f * MathF.Tan(MathUtil.DegreesToRadians(cameraService.VerticalFieldOfView / 2)) * distanceToSelectedEntity;
// 正交相机：SizeFactor * DefaultScale * OrthographicSize
```
- ImGuizmo `ComputeContext()`（`src/ImGuizmo.cpp` ~1226）用“相机右向量投到屏幕的长度”求 `mScreenFactor`，效果相同。
- PolyView：在新的 `Gizmo/TransformGizmo.cs`（program）里：`scale = GizmoPixels / viewportHeightPx * 2 * tan(fovY/2) * distance(eye, pivot)`，`GizmoPixels` 取 Blender 默认约 75 px，并乘 WPF 的 DPI 缩放。手柄世界矩阵 `Matrix4x4.CreateScale(scale) * Matrix4x4.CreateTranslation(pivot)`（行向量顺序）。

### 4.2 几何与外观（照 Blender）
- Stride `TranslationGizmo.cs` 第 78–121 行：每根轴 = 细圆柱 + 锥头；每个平面手柄 = 一块半透明小方片 + 两条边框，方片放在 `(0, L/2, L/2)`，**正反两面各画一次**避免背面剔除。
- ImGuizmo 平面手柄占轴长的 `quadMin=0.5 ~ quadMax=0.8`（第 829 行），并且**当视线几乎平行于某轴/平面时隐藏它**（`ComputeTripodAxisAndVisibility`），防止拖出无穷大位移。PolyView 照做：轴与视线夹角 < 约 5° 就淡出不可拾取（Stride 用 `MinimumRayAngle = 2.5°`）。
- 中心白色小圆（自由移动）：ImGuizmo 用屏幕空间判定，距中心 < 约 10 px 即命中（`mScreenSquareMin = center ± 10`）。
- 旋转：三色圆环 + 屏幕空间白色外环。ImGuizmo 外环半径 `screenRotateSize * 屏幕高`，命中条件 `|dist - R| < 4px`（第 2212 行）；圆环只画朝向相机的半圈（用法线与视线点积裁掉背面）。Blender 的“轨迹球”（中心区域自由旋转）同理：dist < 内圈半径时按鼠标 dx/dy 绕相机 up/right 旋转。
- 缩放：轴末端小方块；ImGuizmo 中心等比缩放命中环 `17px ≤ dist < 23px`。
- 绘制状态：手柄最后画，**清深度后画**（或深度测试关），保证总在最上层；用不受光照的纯色着色器。
- 悬停高亮：每帧 MouseMove 做一次手柄拾取，命中项颜色变亮（Blender 是变白/变亮黄），不需要重新建几何，只改常量缓冲里的颜色。

### 4.3 拖拽数学
- **射线-平面求交**（ImGuizmo 第 1000 行，MIT，移植成 C#）：
```csharp
// plane = (n, d) 满足 dot(n, p) = d
static float IntersectRayPlane(Vector3 o, Vector3 dir, Vector3 n, float d)
{
    float denom = Vector3.Dot(n, dir);
    if (MathF.Abs(denom) < 1e-6f) return -1f;        // 平行
    return -(Vector3.Dot(n, o) - d) / denom;
}
```
- **单轴移动**：选一个包含该轴、且最正对相机的平面（法线 = `Normalize(Cross(axis, Cross(viewDir, axis)))`），按下时记录交点 `p0`，拖动时交点 `p1`，位移 = `Dot(p1 - p0, axis) * axis`。这正是 Stride `TransformationGizmo.cs` 第 304–334 行 `ProjectionPlane` 的做法。
- **平面移动**：直接用该平面（如 XZ 平面法线 = Y），位移 = `p1 - p0`。
- **自由移动（中心圆）**：平面法线 = `-viewDir`，过 pivot。Flax `TransformGizmoBase.cs` 也是 `new Plane(-Normalize(gizmoToView), ...)`。
- **旋转角**（ImGuizmo `ComputeAngleOnPlan`，第 1366 行，MIT，移植）：
```csharp
float t = IntersectRayPlane(ray.Origin, ray.Direction, axis, Vector3.Dot(axis, pivot));
Vector3 local = Vector3.Normalize(ray.Origin + ray.Direction * t - pivot);
Vector3 perp = Vector3.Normalize(Vector3.Cross(startVec, axis));
float angle = MathF.Acos(Math.Clamp(Vector3.Dot(local, startVec), -1f, 1f));
angle *= Vector3.Dot(local, perp) < 0f ? 1f : -1f;
```
  注意 ImGuizmo 是左手坐标习惯，PolyView 右手：符号可能要反，用长方体绕 Y 转 +90° 验证一次。
- **轴命中判定**（ImGuizmo `GetScaleType`，第 2140 行）：把轴两端投到屏幕，算鼠标到该**屏幕线段**的最近点距离 < 12 px 即命中——比 3D 包围盒判定（Stride 的做法）更稳，推荐 PolyView 用这种。

## 5. 【P1】撤销 / 重做

**来源**：Stride [`IUndoRedoService.cs`](https://github.com/stride3d/stride/blob/master/sources/presentation/Stride.Core.Presentation/Services/IUndoRedoService.cs)、[`UndoRedoService.cs`](https://github.com/stride3d/stride/blob/master/sources/presentation/Stride.Core.Presentation/Services/UndoRedoService.cs)、`Dirtiables/PropertyChangeOperation.cs`、`CollectionChangeOperation.cs`。

**怎么做的**：`CreateTransaction()` 返回 `IDisposable`，事务里产生的多个操作（属性改动、集合增删）合成一条历史记录；可嵌套；`using` 结束即提交。每个 Operation 自己实现 Undo/Redo。还有 `Done/Undone/Redone` 事件给 UI 刷新，以及“脏标记”（是否有未保存修改）。

**PolyView 怎么接**（program，新增 `Core/UndoStack.cs`）：先做精简版，不需要 Stride 的全部复杂度：
```csharp
public interface IEditCommand { string Name { get; } void Do(); void Undo(); }
public sealed class UndoStack {
    readonly List<IEditCommand> _items = []; int _cursor;      // _cursor 之前是可撤销的
    public event Action? Changed;
    public void Push(IEditCommand c, bool alreadyDone = true) {
        _items.RemoveRange(_cursor, _items.Count - _cursor);
        if (!alreadyDone) c.Do();
        _items.Add(c); _cursor++; Changed?.Invoke();
    }
    public bool CanUndo => _cursor > 0;  public bool CanRedo => _cursor < _items.Count;
    public void Undo() { if (CanUndo) { _items[--_cursor].Undo(); Changed?.Invoke(); } }
    public void Redo() { if (CanRedo) { _items[_cursor++].Do(); Changed?.Invoke(); } }
}
```
- 命令：`TransformCommand(id, oldTrs, newTrs)`（手柄松开 / 变换面板回车时推入）、`SetVisibleCommand`、`DeleteObjectCommand`（保存 `MeshData` 以便恢复）、`AddObjectsCommand`。
- 快捷键：`ModelViewport.HandleKey` 加 Ctrl+Z / Ctrl+Shift+Z（Blender 习惯），Ctrl+Y 兼容。
- 菜单文字：english 在 `UiText.cs` 加 `Undo`（撤销）、`Redo`（重做）、`UndoNothing`。

## 7. 【P1】灯光 / 相机视口图标

**来源**：Stride `Gizmos/LightPointGizmo.cs`、`LightSpotGizmo.cs`、`LightDirectionalGizmo.cs`、`CameraGizmo.cs`（MIT）：每种灯是一个**始终朝向相机的图标面片（billboard）**+ 线框（点光的范围球、聚光的锥、平行光的方向箭头），图标也用 §4.1 的恒定屏幕尺寸；相机画视锥线框。Flax 的 debug draw 思路相同（只参考）。

**PolyView 怎么接**（program，`SceneRenderer` 新增 `DrawLightIcons()`；数据来自 PolyView软件开发 的导入器 `Directional/Point/Spot/Area` 字段）
- 统一走一个 `LineList` 动态顶点缓冲，每帧重建（灯数量少，开销可忽略），按 07 规格画：点光 = 小圆 + 外圈；日光 = 圆 + 方向虚线；聚光 = 锥线（`SpotSize`）；面光 = 矩形（`Size`）+ 法线；相机 = 视锥（`yfov`、宽高比）。
- 圆环用 billboard：在顶点着色器里用视图矩阵的 right/up 展开，保证永远正对屏幕。
- 拾取：灯/相机用“到图标中心的屏幕距离 < 10 px”判定，和手柄同一套代码。
- 选中的灯同样走 §2 的描边（把线画进遮罩）。

## 8. 【P2】拾取加速（BVH / 八叉树）

**来源**：Helix [`StaticMeshGeometryOctree.cs`](https://github.com/helix-toolkit/helix-toolkit/blob/develop3/Source/HelixToolkit.SharpDX/Utilities/Octrees/StaticOctrees/StaticMeshGeometryOctree.cs)、`StaticOctree.cs`（MIT）：按三角形包围盒建**静态八叉树**，用扁平数组存节点（不是对象树），命中测试时先测节点 AABB 再测三角形；另有 `BoundableNodeOctree.cs` 做“物体级”加速。

**PolyView 怎么接**（program，`Core/Picking.cs`）
- 两级：物体级先 `RayAabb`（已有）按 `tEnter` 排序，近的先测，命中后跳过 `tEnter` 更远的物体（立刻省掉大部分）；三角形级给 >1 万面的网格在后台线程建 BVH（SAH 或中点切分，叶子 4–8 个三角形，节点用 `struct` 数组）。
- BVH 在导入完成时建（PolyView软件开发 可在导入器里顺带产出三角形包围盒，避免二次遍历）。
- 注意变换：射线转到物体局部空间再测（`Matrix4x4.Invert(world)`），BVH 不随移动重建。

## 9. 【P2】吸附

- ImGuizmo `ComputeSnap`（第 1340 行，MIT）：带“吸附张力”，接近网格整点时才吸，手感更好：
```csharp
static float Snap(float v, float step, float tension = 0.5f) {
    if (step <= 1e-6f) return v;
    float mod = v % step, r = MathF.Abs(mod) / step;
    if (r < tension) return v - mod;
    if (r > 1f - tension) return v - mod + step * MathF.Sign(v);
    return v;
}
```
- Flax 思路：累计未吸附的增量 `delta`，按步长取整后从累计值中减掉（防止慢速拖动永远不动）；支持绝对吸附（世界网格）和相对吸附。
- PolyView：按住 Ctrl 拖动开启（Blender 习惯），移动步长 = 网格格距，旋转 5°/15°（Shift 精调），缩放 0.1。english 加 `SnapOn` 提示文字。
