# 07 灯光规格（对齐 Blender）

> 作者：novel · 2026-10-23 · 依据：Blender 5.2 手册 *Lighting ‣ Light Objects*（docs.blender.org/manual/en/latest/render/lights/light_object.html）、glTF `KHR_lights_punctual`、Assimp `aiLightSourceType`，以及 `feat/import-xiaoB` 上的 `MeshData.cs`（`SceneNode`/`SceneLight`/`SceneCamera`）与 `SceneRenderer.cs`。
> 目标：灯光类型、参数、视口图标和显示效果尽量与 Blender 一致；显示效果以 **Eevee 视口** 为参照，第 1 阶段不做 Cycles 式光线追踪（无光追阴影、无全局光照）。

## 1. Blender 的灯光与「世界」

Blender 只有 4 种灯光对象；「环境光」不是灯，而是 **World（世界）** 的背景颜色/强度（或环境贴图）。

| 类型 | 说明 | 主要参数 |
|---|---|---|
| Point 点光 | 向所有方向均匀发光，随距离衰减 | Color、Power（W）、Radius（球形光源半径，越大高光/阴影越软）、Soft Falloff |
| Sun 日光 | 无限远、单一方向、强度恒定；位置不影响结果，只看旋转 | Color、Strength（W/m²，辐照度）、Angle（角直径） |
| Spot 聚光 | 从锥顶沿方向发出锥形光束 | Color、Power（W）、Radius、Spot Size（外锥全角，1°–180°）、Blend（0–1，内锥柔化比例）、Show Cone |
| Area 面光 | 面光源，阴影边缘柔和 | Color、Power（W）、Shape：Square/Rectangle/Disk/Ellipse，Size 或 Size X/Size Y |

公共参数：Color、Temperature（色温 K）、Exposure（乘 2^exposure）、Normalize（默认开：改尺寸时总功率不变）。
参考值（手册）：蜡烛 0.05 W、800 lm LED 2.1 W、汽车大灯 22 W（Spot 125°）；晴天日光 1000 W/m²、阴天 200–500 W/m²。

**World**：背景颜色 `Color` + `Strength`，在我们这里作为环境光（均匀环境照明），不是灯光节点。

## 2. 导入映射（负责：PolyView软件开发）

### 2.1 glTF `KHR_lights_punctual`

| glTF | 我们的类型 | 单位/换算（与 Blender glTF 导入器一致，"Standard" 光照模式） |
|---|---|---|
| `point` | Point | intensity 为 cd（坎德拉）。Power(W) = cd × 4π / 683 |
| `spot` | Spot | cd 同上换算；Spot Size = 2 × outerConeAngle；Blend ≈ (outer − inner) / outer（Blender 导入器的近似） |
| `directional` | Sun | intensity 为 lux，Strength(W/m²) = lux / 683（与 Blender glTF 导入器一致，PolyView软件开发已按此实现，`7d2149d`） |

- `range` 存入 `SceneLight.Range`（0 = 无限），着色时作为平滑截断。
- glTF 没有面光和环境光：测试模型 `camera_light_test.glb` 里的 **Area 灯** 和 **World** 写在节点/场景的 `extras` 里（约定字段见 §6），导入器读 extras 还原。
- 灯光方向：glTF 灯指向本地 −Z，与 Blender 一致；方向 = `World` 矩阵变换后的 −Z。

### 2.2 Assimp `aiLightSourceType`

| Assimp | 我们的类型 | 常见来源格式 |
|---|---|---|
| `aiLightSource_POINT` | Point | FBX、DAE、3DS、Blend、glTF（经 Assimp） |
| `aiLightSource_DIRECTIONAL` | Sun | FBX、DAE、glTF |
| `aiLightSource_SPOT` | Spot（`mAngleOuterCone/InnerCone` 为半角） | FBX、DAE、3DS、glTF |
| `aiLightSource_AREA` | Area（`mSize`） | FBX 等少数格式 |
| `aiLightSource_AMBIENT` | 不建灯，合并进 `MeshData.World`（颜色相加） | DAE、FBX |
| `aiLightSource_UNDEFINED` | Unknown，跳过并写 `Notice` | — |

Assimp 的强度单位不统一（多为颜色×强度，没有物理单位）：Power 取 `|mColorDiffuse|` 的最大分量 × 经验系数（默认 1000 W 点光等效，写在常量里），并在 `Notice` 标注「强度已估算」。

### 2.3 不支持/降级
- STL、OBJ 没有灯光：只有一个根 Mesh 节点，场景使用默认视口灯光。
- 未知类型或缺参数：使用 Blender 默认值（Point 1000 W、Radius 0.1 m；Sun 1 W/m²；Spot 45°、Blend 0.15；Area Square 1 m）。
- 文件里没有任何灯：自动用「默认视口光」模式（§4.1），不报错。

## 3. 视口显示（负责：program）

所有灯光和相机图标都以 **叠加线框**（overlay，不写深度或单独深度测试，线宽 1 px，DPI 缩放）画出，样式参照 Blender：

| 对象 | 图标 |
|---|---|
| Point | 屏幕对齐的小实心点 + 外圈圆环；Radius > 0 时再画半径圆 |
| Sun | 圆 + 一圈短射线 + 沿光方向的虚线（长度约 1 个场景单位） |
| Spot | 锥顶点 + 锥体线框（外锥 = Spot Size），锥口画外圆与内圆（Blend），以及方向线 |
| Area | 按 Shape 画正方形/矩形/圆/椭圆轮廓 + 法线方向线 |
| Camera | 四棱锥（视锥，按 YFov/AspectRatio）+ 顶部小三角表示「上」 |

- 颜色：未选中为深灰/黑（与 Blender 一致），选中为橙色，活动对象为亮橙；灯光颜色不影响图标颜色。
- 拾取：灯光、相机按图标的屏幕包围盒/线段距离（≤ 6 px）参与拾取，与模型拾取共用 05 的选择接口；点空白或 Esc 取消。
- 图标大小随相机距离保持屏幕尺寸大致恒定（Point/Sun），Spot/Area/相机按真实尺寸。

## 4. 着色（负责：program）

### 4.1 两种模式（工具条切换）
1. **默认视口光（类 Blender Solid）**：保留现有 `SceneRenderer` 的半球光 + 主光（`hemisphere` + `0.75 × key`，光方向跟随相机），不受导入灯光影响。
2. **场景灯光（类 Eevee 视口 Material Preview/Rendered）**：使用导入的灯光 + World 环境光。

### 4.2 场景灯光公式
- 材质：Blinn-Phong（漫反射 Lambert + 高光，glossiness 固定），第 2 阶段可换简单 PBR（GGX）。
- Point/Spot：辐射强度 I = Power / (4π)，照度 ∝ I / d²（反平方衰减），`Range` > 0 时乘平滑截断 `saturate(1 − (d/range)^4)^2`。
- Spot：在外锥内用 `smoothstep(cos(outer), cos(inner), dot(-L, dir))`，inner = outer × (1 − Blend)。
- Sun：E = Strength，方向恒定，无衰减。
- Area：第 1 阶段近似为中心点的点光，按 Lambert 乘 `max(dot(n_area, -L), 0)`（单面），Power 不变；后续可换 LTC。
- 环境光：`albedo × World.Color × World.Strength`。
- 曝光：最终颜色 × 曝光系数后做 Filmic/ACES 近似色调映射，避免 1000 W 灯直接过曝；默认曝光使 Blender 默认 1000 W 点光在 4 m 处观感接近。
- 第 1 阶段不做阴影。

### 4.3 常量缓冲
- 现有 `FrameConstants`（b0）不动；新增 `cbuffer Lights : register(b1)`，最多 **16 盏灯**（每盏 64 字节：位置+类型、方向+range、颜色×强度、cosInner/cosOuter/面光尺寸），外加 `LightCount`、`AmbientColor`。
- 超过 16 盏：按 Power/距离选前 16 盏，`Notice` 提示。
- 每帧只在灯光或相机变化时写缓冲（沿用按需渲染）。

## 5. 场景列表与属性面板

- 场景列表单独一行 **World**（世界）在最上方，其下是文件 → 节点层级。
- 图标/类型名（english 已提交 `4dad14c`）：`LightPoint`、`LightSun`、`LightSpot`、`LightArea`、`LightAmbient`（用于 World/环境），World 文本随后补上；模型/相机/空节点沿用 `KindMesh`/`KindCamera`/`KindEmpty`。
- 属性面板（只读，第 1 阶段）：
  - 灯光：类型、颜色、Power（W）或 Strength（W/m²）、Radius、Spot Size/Blend、Shape 与 Size X/Y、Range、来源单位（如「glTF cd→W」）。
  - 相机：透视/正交、YFov 或 OrthoHalfHeight、Near、Far、AspectRatio。
  - World：颜色、Strength。

## 6. 数据模型（负责：PolyView软件开发）

在现有 `MeshData.cs` 基础上扩展，保持已有字段兼容：

```csharp
public enum SceneLightType { Directional /*=Sun*/, Point, Spot, Area }
public enum AreaShape { Square, Rectangle, Disk, Ellipse }

public sealed class SceneLight {
    public SceneLightType Type { get; init; }
    public Vector3 Color { get; init; } = Vector3.One;
    public float Intensity { get; init; } = 1f;     // 原始值（cd/lux/Assimp），保留
    public float Power { get; init; }               // Blender 单位：Point/Spot/Area 为 W，Sun 为 W/m²
    public float Radius { get; init; }              // Point/Spot 软尺寸
    public float Range { get; init; }
    public float InnerConeAngle { get; init; }      // 半角，弧度
    public float OuterConeAngle { get; init; }
    public float SpotSize => OuterConeAngle * 2;
    public float SpotBlend { get; init; }
    public AreaShape Shape { get; init; }
    public Vector2 Size { get; init; }              // Square/Disk 只用 X
}
public sealed class SceneWorld {
    public Vector3 Color { get; init; } = new(0.05f);
    public float Strength { get; init; } = 1f;
    public bool FromFile { get; init; }             // 是否来自文件（否则为默认值）
}
// MeshData 新增：public SceneWorld World { get; init; } = new();   // 永远不为 null
```

- `Directional` 在界面上显示为 Sun（不改枚举名，避免破坏已有代码）。
- 环境光（Assimp `AMBIENT`）不生成灯光节点，只累加到 `MeshData.World`。
- 以代码为准：类型 `Directional`/`Point`/`Spot`/`Area`；字段 `Power`、`Radius`、`SpotSize`、`SpotBlend`、`Shape`、`Size`（Vector2）；`MeshData.World` 永远不为空（Color、Strength、FromFile）。完整说明见 docs/04。
- glTF extras 约定（测试模型用）：灯节点 `extras.polyview_light = { "type":"area", "shape":"rectangle", "size":[2,1], "power":100 }`；场景 `extras.polyview_world = { "color":[r,g,b], "strength":1 }`。
