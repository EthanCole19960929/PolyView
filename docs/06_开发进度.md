## 6. 创新点

1. **内置零配置 MCP**：PolyView 自带 MCP 服务，自动扫描并一键接入各种 AI，AI 能直接操控场景。
2. **AI 可调用原则**：每个新功能同时提供命令层接口，界面能做的 AI 也能做。
3. **Blender 联动**：与 Blender 互通，并计划双向实时同步，复用 MCP 指令。
4. **高度还原 Blender 4.2**：界面、快捷键、手柄、菜单和偏好设置都按 Blender 做，Blender 用户零学习成本。
5. **轻量高性能**：D3D11 按需渲染，静止不占 GPU。
